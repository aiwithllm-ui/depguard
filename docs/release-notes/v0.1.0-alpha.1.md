# DepGuard v0.1.0-alpha.1

> **ALPHA:** This release is intended for early contributors and evaluators, not production-critical dependency approval workflows.

DepGuard produces local, reproducible compatibility evidence for a direct npm dependency upgrade in a specific project. It creates baseline and candidate twins, runs configured commands in a Docker sandbox with network denial, compares supported observations, and emits Compatibility Evidence V1.

## Included

- npm-first project resolution and controlled package metadata/artifact handling.
- Docker-backed verification with baseline/candidate twins and policy findings.
- Frozen Compatibility Evidence V1, Canonicalization V1, Attestation V1, and Verification Methodology V1 protocols with conformance fixtures.
- Locally signed DSSE/in-toto attestations and offline attestation verification.
- Opt-in PostgreSQL global compatibility network MVP.
- Server-side verified GitHub Actions Sigstore CI identity support for an exact submitted attestation.
- CI for workspace quality gates, protocol conformance, and an isolated PostgreSQL trust-boundary integration test.

## Important limits

DepGuard provides evidence, not an absolute safety guarantee. npm is the only primary ecosystem in this alpha. Verification requires Docker; observation is partial and network execution is policy-denied, not fully traced. The network is an MVP. A verified GitHub CI identity is not proof of maintainer approval or a package release endorsement.
