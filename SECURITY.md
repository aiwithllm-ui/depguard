# Security policy

Please do **not** file a public issue for a sandbox escape, credential exposure, unsafe execution default, evidence forgery, authentication weakness, or other suspected vulnerability.

Report privately through [GitHub private vulnerability reporting](https://github.com/aiwithllm-ui/depguard/security/advisories/new). Include a clear impact assessment and minimal reproduction steps; do not attach secrets, live credentials, or malicious archives unless maintainers arrange a safe transfer channel. If private reporting is unavailable, use the repository owner’s private GitHub contact route to request a secure channel rather than opening a public issue.

Maintainers will acknowledge reports, coordinate remediation privately, and publish a disclosure after a fix is available. This project makes no response-time guarantee during alpha.
