# Governance

DepGuard is maintainer-led during the alpha. Contributors are welcome through issues and pull requests; maintainers make final merge and release decisions.

Changes to sandbox boundaries, privacy guarantees, security policy, evidence schemas, frozen protocol semantics, or public exit behavior require maintainer review and a documented decision record in `docs/adr/`. Frozen V1 protocol changes additionally require an approved compatibility proposal before code is written.

Maintainers should make decisions transparently in issues or pull requests, recuse themselves where conflicts matter, and use the [security policy](SECURITY.md) for vulnerabilities rather than public discussion.
